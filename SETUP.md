## 🔑 **What You Need To Do (Only 3 Steps)**

### **Step 1: Get Your API Keys (15 minutes)**

#### **Groq API Key:**
1. Go to https://console.groq.com
2. Sign up (free)
3. Click "API Keys" 
4. Click "Create New API Key"
5. Copy the key (looks like: `gsk_abc123xyz...`)

#### **Gemini API Key:**
1. Go to https://aistudio.google.com/app/apikey
2. Click "Create API Key"
3. Copy the key (looks like: `AIza_abc123xyz...`)

#### **OpenRouter API Key:**
1. Go to https://openrouter.ai/auth/signup
2. Sign up (free)
3. Go to Settings → API Keys
4. Copy the key (looks like: `sk-or-v1_abc123xyz...`)

---

### **Step 2: Add Keys to `.env` File (2 minutes)**

**File Location:** `voxel-gg/backend/.env`

**Open the file and replace the XXX with your actual keys:**

```
GROQ_KEY=gsk_your_actual_key_here
GEMINI_KEY=AIza_your_actual_key_here
OPENROUTER_KEY=sk-or-v1_your_actual_key_here
PORT=3000
NODE_ENV=production
```

**Save the file.**
