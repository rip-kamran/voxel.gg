📥 Install the Plugin

Follow these steps to install Voxel.gg in Roblox Studio:

Step 1: Copy the Plugin Code

Click the button below to copy the complete plugin code:

Step 2: Open Roblox Studio

Open any Roblox game in Roblox Studio.

Step 3: Install Plugin

  1. Go to Home → Plugins → Manage Plugins
  2. Click Create New Plugin
  3. Paste the plugin code you copied
  4. Click Save
  5. Reload or restart Studio

Step 4: Use It!

You'll see a 🤖 Voxel button in your toolbar. Click it to open the generator!

💡 Tip: Make sure you have an internet connection. The plugin communicates with Voxel's servers to generate code.
