## 🔧 Technical Details

### Architecture
```
User → Plugin (Luau)
  ↓ (HTTP POST)
Backend (Node.js on Railway)
  ├─ Validates request
  ├─ Checks user credits
  ├─ Calls AI provider
  │  ├─ Groq (14,400/day) ← First choice (fastest)
  │  ├─ Gemini (1,000/day) ← Second choice
  │  └─ OpenRouter (28,800/day) ← Third choice
  ├─ Cleans code (#!strict compliance)
  └─ Returns Luau code
  ↓ (HTTP response)
Plugin displays code
  ↓ (Click insert)
Code inserted into Studio
```
